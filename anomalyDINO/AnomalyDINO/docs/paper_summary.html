The AnomalyDINO Paper

Damm, Laszkiewicz, Lederer, Fischer — Ruhr University Bochum & University of Hamburg · WACV 2025 · arXiv:2405.14529

"Anomaly detection requires better representations" — so skip the classifier, skip the training, and let a strong frozen backbone plus a memory bank do the work.

02 The method, in one paragraph

Full mechanism and diagrams live in docs/architecture.html — this is the two-sentence version plus the paper's own equations.

Embed a few reference images with a frozen DINOv2, store their patch vectors in a memory bank M, then score a test patch p by its distance to the nearest bank entry, dNN(p; M) := minp_ref∈M d(p, p_ref) using cosine distance. The image score aggregates all patch distances via the mean of the top 1% — an empirical value-at-risk at the 99th percentile, chosen because it weights the defective region heavily without letting one noisy patch dominate. Two cheap preprocessing steps do the rest of the work: masking (PCA-threshold the patch tokens to drop background) and rotation augmentation (8× per reference image, to widen a thin memory bank).

04 What actually moves the needle

Five ablation findings worth remembering, each with the paper's own number attached.

  1. Preprocessing is worth ~2 AUROC points on average (masking + rotation vs. neither) — but it's a per-category decision, not a free lunch: blindly rotating the reference set can hurt when orientation itself is the defect (a "misplaced"/rotated transistor stops looking anomalous once rotation is baked into the memory bank).
  2. Rotation alone can flip a category from unusable to strong — MVTec-AD "Screw" jumps from 65.6% to 89.2% 1-shot AUROC just by augmenting the single reference image with 8 rotations.
  3. The aggregation statistic matters more than it looks — mean of the top-1% patch distances beats taking the raw maximum distance (98.3% vs. 97.4% AUROC, MVTec-AD 16-shot); it's a small but consistent, free improvement.
  4. Bigger backbone ≠ better — the smallest DINOv2 (ViT-S, 21M params) is the best performer on MVTec-AD; larger backbones (B/L/G) only pull ahead on VisA, and only once k≥8. Complex multi-object scenes reward capacity; simple single-object scenes don't.
  5. Self-supervision is what's doing the work, not "being a ViT" — swapping DINOv2 for a same-sized ImageNet-supervised ViT costs at least 4 AUROC points on both datasets, with everything else held fixed.

05 Where it breaks

Two concrete failure modes the authors document themselves (Appendix B) — both follow directly from scoring patches independently.

Semantic anomalies are invisible to it

The method only asks "does this patch look like a normal patch?" — never "are these normally-fine parts in the right arrangement?" Their worked example: a Cable with two wire colors swapped. Each individual patch still matches something in the memory bank (both colors exist somewhere in a normal cable), so nothing looks locally wrong. Detection AUROC on this specific failure case: 50.2% — chance level. A "Bent Wire" cable (a genuinely different-looking, sensory anomaly) is detected fine by the same pipeline.

One bad reference image poisons the memory bank

1-shot detection is only as good as the single sample you happened to pick. Worked example: a Capsule reference image where the imprinted text is rotated out of view — every other capsule that does show its text then gets flagged as anomalous, for the wrong reason. This is the direct cause of the high 1–2 shot variance visible in the paper's own result tables; it shrinks fast as k grows and M gets more diverse.

06 The batched zero-shot trick, precisely

Appendix D's extension, stated exactly as the paper derives it.

With no reference set, score each test sample x(j) against a memory bank built from every other test sample in the batch: Mj := ⋃ {pm | f(x(i)) = (p₁,…,pₙ)} for x(i) ∈ Xtest \ {x(j)}. Because Mj now contains anomalous patches too, plain 1-NN isn't safe — one lucky match to another defect would look "normal." The fix: replace the nearest neighbor with the mean of the closest 0.1% of patches in Mj, leaning on the assumption that most patches in a batch really are normal. Same downstream top-1% image aggregation as the few-shot path. Net cost: about the same ~60ms/sample.
