Detection performance vs. supervision

Zero-shot has no support set at all — it scores each test image against the others in its batch. From 1-shot onward, a growing set of known-good reference images builds the memory bank.

Method

Patch-based kNN over frozen DINOv2 patch tokens; FAISS L2-normalized search, k=1; image score = mean of the top 1% most anomalous patches.

Commands

  • run_anomalydino.py --dataset VisA --shots 1 2 4 8 16 --num_seeds 3 --preprocess agnostic
  • run_anomalydino_batched.py --dataset VisA
  • run_anomalydino.py ... --eval_segm --tag segm (segmentation)

Data

Raw VisA release converted to the MVTec-style train/test/good/bad layout via split_csv/1cls.csv (symlinked, not copied).
